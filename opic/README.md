# OPIc IH 트레이너

OPIc IH를 목표로 혼자 연습하는 웹 앱입니다. `index.html`을 브라우저로 열면 바로 쓸 수 있고, 설치할 것은 없어요.

## 들어 있는 것

| 탭 | 내용 |
|---|---|
| 학습 | 유형별 IH 템플릿 8개(묘사, 루틴, 경험, 비교, 롤플 11·12·13, 자기소개), 만능패턴 55문장, 주제별 기출 유형(선택 9개, 돌발 6개), 롤플레이 상황 14개, IH 전략, 참고 영상 목록 |
| 패턴카드 | 한국어를 보고 영어로 말해본 뒤 뒤집어 확인. 외운 카드 진도 표시 |
| 답변연습 | 문제 뽑기 → 문제 듣기 → 타이머 → 영어로 답변 입력(키보드 음성 입력 가능) → IH 기준 자동 채점 → AI 첨삭 (claude.ai에서 열었을 때) |
| 모의고사 | 실제 순서의 15문항(자기소개, 선택 2세트, 돌발 1세트, 롤플 3문항, 비교 2문항). 문제 듣기는 2회까지 |
| 기록 | 답변 수, 평균 단어 수, 유형별 충족률, 지난 답변 |

## 자동 채점 기준

- 분량: 120단어 이상 (롤플 11은 90단어, 자기소개는 70단어)
- 연결어 5개 이상, 만능패턴 4개 이상
- 자연스러운 시작과 마무리 문장
- 경험 문제: 과거시제 8개 이상, 사건 전개 표현
- 루틴은 순서 표현, 비교는 과거와 현재의 대비, 묘사는 디테일과 내 생각
- 롤플 11은 질문 3개 이상, 롤플 12는 사과와 대안 2개 이상

글자로만 판단하는 자가진단이라 발음과 속도는 반영되지 않아요.

## 참고 영상

12개 영상 모두 강지완오픽TV 영상입니다. 클라우드 환경에서는 YouTube가 자동 접속을 막아서 자막을 읽지 못했어요. 그래서 영상 제목에 나온 주제 구성(만능패턴, 롤플 11·12·13, 돌발 6개 주제, 선택주제 150문장)에 맞춰 내용을 직접 작성했습니다. 영상 링크는 앱의 '학습 → 영상 목록'에 있어요.

## 파일

- `opic-ih-trainer.html`: 앱 원본 (claude.ai 아티팩트로 게시하는 파일)
- `index.html`: 원본에 HTML 기본 틀을 씌운 단독 실행용 파일. 원본을 고치면 아래 명령으로 다시 만드세요.

```sh
{ printf '<!doctype html>\n<html lang="ko"><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover"></head><body>\n'; cat opic-ih-trainer.html; printf '\n</body></html>\n'; } > index.html
```
